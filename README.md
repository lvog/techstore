# 🛍️ Techstore

TechStore — це тестовий проект, реалізований для компанії **DARTC**.
Проект реалізовано з дотриманням дизайну (pixel perfect) та адаптовано під desktop.

## 🚀 Live Demo

[Live Demo](https://lvog.github.io/techstore)

## 📌 Основний функціонал

- Багаторівневе адаптивне меню
- Карусель (Splide)
- Додавання товарів в обране з оновленням лічильника
- Валідація форми

## 🛠️ Технології

- Webpack
- JavaScript (ES6+)
- HTML5
- SCSS
- Splide.js


## ⚙️ Встановлення та запуск

### 1. Клонування репозиторію

```bash
git clone https://github.com/lvog/techstore.git
```

### 2. Перехід у папку проекту

```bash
cd techstore
```

### 3. Встановлення залежностей

⚠️ Перед встановленням залежностей ознайомтесь з [webpack-markup-starter](https://github.com/lvog/webpack-markup-starter) який використовується в цьому проекті.

```bash
npm install
```

### 4. Запуск проекту

```bash
npm run dev
```

### 5. Збірка проекту для продакшену

```bash
npm run build
```
